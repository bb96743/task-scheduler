## 环境与账号说明（对应第 9 条）

本项目是调度中心的后端服务，本身不对终端用户开放注册登录，所有接口默认内网可信调用；
因此没有「测试账号」这个概念，验收时直接访问即可，无需登录。

本地起测试环境只需要一条命令（JDK 21）：

```bash
java -jar backend/target/task-scheduler-1.0.0.jar --spring.profiles.active=demo
# 打开 http://localhost:8080 即为管理台，已预置 5 个示例任务
```

如需长期可访问的公网测试环境，可将同一 jar 部署到任意云主机（约 300MB 内存即可），
换 MySQL 只需设置三个环境变量：`DB_URL` / `DB_USER` / `DB_PASSWORD`。
