## 四、如果评审追问「怎么验证」

最短路径（不需要装 MySQL / Redis / ZooKeeper）：

```bash
unzip task-scheduler-submission.zip && cd task-scheduler/backend
mvn -DskipTests package
java -jar target/task-scheduler-1.0.0.jar --spring.profiles.active=demo
# 浏览器打开 http://localhost:8080
```

首页应看到：任务总数 5、启用中 4、告警记录 0、右上角「在线节点 1/1」。
五分钟内能看到 `demo-fail-task` 的 CRON → RETRY#1 → RETRY#2 完整失败链路和一条告警；
`demo-shard-task` 每 45 秒跑一次 4 分片并行。
